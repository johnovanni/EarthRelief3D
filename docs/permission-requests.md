# Permission requests (drafts for the owner to send)

Drafted 2026-11-23 for Plan 3 (task 1). **Nothing has been sent.** The owner sends each one, adds the sender's name and
address where `[SENDER]` stands, and checks the contact address on the organisation's own site first (only UNODC's
address was given to us; the other three are placeholders). Until a written yes arrives, none of these four sources goes
into the app (spec C13, ruling P3-3): detention shows curated camp sites with citations, and the Early Warning Project risk list
stays a link.

Section 5 (ACAPS, Plan 4) is optional: the app reads ACAPS's workbook live from HDX and commits none of it, so it works without a reply.

What the app is, the same in all four letters: free, public on GitHub (https://github.com/johnovanni/EarthRelief3D),
MIT licence, educational, no ads, no sound, no personal data collected, and every fact on screen shows its source and
an "as of" date.

## 1. UNODC: prison population data

**To:** unodc-stats@un.org
**Subject:** Request for permission to show UNODC prison statistics in a free educational app

Dear UNODC Statistics team,

I am writing to ask for permission to use a small part of the UNODC data portal's prison statistics (https://data.unodc.org)
in a free, non-commercial educational program.

EarthRelief3D is a Windows desktop program that shows humanitarian crises on a 3D globe: armed conflict, food insecurity,
disease outbreaks, displacement and, in the next version, detention. It is free, has no advertising, collects no personal
data, and its source code is public under the MIT licence at https://github.com/johnovanni/EarthRelief3D. Every number
on screen is shown with its source and the date it refers to.

What we would show: for each country, the "persons held in prisons" count and the rate per 100,000 population for the
latest year UNODC reports (and, in the country panel, the year), exactly as published, with the line "Source: United Nations
Office on Drugs and Crime (UNODC), data.unodc.org, <year>, retrieved <date>". We would not alter the figures, and nothing
would be shown that implies UNODC endorses the program. We would prefer to download the figures when the program runs and
keep only a local cache on the user's computer, not to republish the dataset; if UNODC prefers a different arrangement, we
will follow it.

UNODC's terms of use say the data is for personal, non-commercial use, without redistribution or derivative works, so we
have not included any of it and will not until you reply. Could you tell us whether this use is permitted, and the
attribution wording you want?

Thank you for your time.

[SENDER: name, and a reply address]
