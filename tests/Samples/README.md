- `revocation_excerpt.txt`: https://apps.irs.gov/pub/epostcard/data-download-revocation.zip (the IRS file dated 2026-11-17, 47,625,777 bytes; one text file, 148,494,106 bytes, no header, 12 fields: `EIN|Legal name|Doing business as|Address|City|State|ZIP|Country|Exemption type|Revocation date|Posting date|Reinstatement date`). 24 real rows: the first 14, three that carry a reinstatement date (010028850 and 010043788, twice), and others spread through the file's start. - `index_2026_excerpt.csv`: https://apps.irs.gov/pub/epostcard/990/xml/2026/index_2026.csv (the IRS file dated 2026-11-18, 64,408,416 bytes; header `RETURN_ID,FILING_TYPE,EIN,TAX_PERIOD,SUB_DATE,TAXPAYER_NAME,RETURN_TYPE,DLN,OBJECT_ID,XML_BATCH_ID`). 25 real rows: the first 12 data rows (990, 990EZ and 990PF returns), and every row in the file for the six charities above (990 and 990-T returns; MSF USA has only a 990-T here), for Bangor Childrens Home (three 990 periods: 202408, 202412, 202508, for the "latest return" test) and for Portland Maine Elks Lodge. - `irs990_sample.xml`: one real Form 990 return, American National Red Cross, EIN 53-0196605, tax period 202506 (period ending 2025-06-30; the schema's own `TaxYr` is 2024), return type 990, schema 2024v5.1, OBJECT_ID 202640829349300109, from https://apps.irs.gov/pub/epostcard/990/xml/2026/2026_TEOS_XML_03A.zip (260 MB zip), entry `202640829349300109_public.xml` (146,792 bytes as published). **Trimmed** (final review F5): people's names, compensation, preparer and phone details removed; only the header's `TaxYr`, `TaxPeriodBeginDt`, `TaxPeriodEndDt`, `ReturnTypeCd`, the filer's EIN and name, and Form 990 Part IX line 25 (`TotalFunctionalExpensesGrp`) are kept, valid XML in the IRS namespace; the test zip is built from the trimmed file. Read by `ZipRangeReader` (HTTP Range requests: about 2 seconds, the zip itself never downloaded), which checks the entry's CRC-32. Part IX line 25: total functional expenses 3,285,857,544; programme services 2,985,109,298 (90.85%). The zip's entry name is `<OBJECT_ID>_public.xml` and its file name is the index's `XML_BATCH_ID` plus `.zip`, under the same year folder as the index.
