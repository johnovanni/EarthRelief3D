## Plan 3 samples (captured 2026-11-23)

Captured by `tools/fetch-samples.ps1 -Set Plan3`, except the synthetic GHO files and `ipc_nga.geojson` (trimmed by a one-off script, ruling R1). Retrieval date for every line below: 2026-11-23.

- `gho_wsh_water_basic.json`, `gho_wsh_sanitation_basic.json`, `gho_uhc_index.json`: **SYNTHETIC, invented by hand (a script outside the repo), contain no WHO data** (ruling R5, as P2-5). Same shape as the live WHO Global Health Observatory OData answer checked on 2026-11-23 (https://ghoapi.azureedge.net/api/WSH_WATER_BASIC, `.../WSH_SANITATION_BASIC`, `.../UHC_INDEX_REPORTED`): `@odata.context`, a `value` array, the same field names and types. Values are invented; the app fetches the real data live. 15 countries (SDN, YEM, AFG, NER, TCD, ISL, USA, CHN, PSE, SOM, SSD, UKR, HTI, COD, MMR), three years each (WASH 2022 to 2024, USA without 2023; UHC 2019, 2021, 2023), `RESIDENCEAREATYPE_TOTL` rows, plus one `_URB` and one `_RUR` series for SDN so the filter can be tested; the UHC file has `Dim1` null. 25 to 30 KB each. Licence: ours (MIT, with the repo). `fetch-samples.ps1` does not write them.
- `hdx_hno_package.json`: https://data.humdata.org/api/3/action/package_show?id=global-hpc-hno (HDX CKAN); CC BY-IGO (`cc-by-igo`); untrimmed. Credit: "OCHA Humanitarian Programme Cycle Tools (HPC Tools), via HDX: Global HPC HNO 2026; CC BY-IGO".
- `hpc_hno_2026.csv`: the resource "Global HPC HNO 2026 CSV" of that package (https://data.humdata.org/dataset/8326ed53-8f3a-47f9-a2aa-83ab4ecee476/resource/edb91329-0e6b-4ebc-b6cb-051b2a11e536/download/hpc_hno_2026.csv); CC BY-IGO; the whole file (134 rows, 20 countries). Credit: "OCHA Humanitarian Programme Cycle Tools (HPC Tools), via HDX: Global HPC HNO 2026; CC BY-IGO".
- `hdx_ipc_nga_package.json`: https://data.humdata.org/api/3/action/package_show?id=nigeria-acute-food-insecurity-country-data; CC0 / public domain (`other-pd-nr`); untrimmed. Credit: "Integrated Food Security Phase Classification (IPC), via HDX; National IPC Technical Working Group".
- `ipc_nga.geojson`: the resource `ipc_nga.geojson` of that package (1,873,647 bytes, 795 features); CC0 / public domain. **Trimmed to 40 features** (2 Point, 2 MultiPolygon, 36 Polygon; `overall_phase` 0 (6), 2 (12), 3 (13), 4 (9)), chosen with a fixed random seed, geometry simplified (Douglas-Peucker 0.004 degrees, 3 decimals), properties untouched; 62,798 bytes. The script that did it is a one-off kept outside the repo (the DataTool does not exist yet); `fetch-samples.ps1 -Set Plan3` leaves the full file in `.downloads/` (git-ignored). Credit: "Integrated Food Security Phase Classification (IPC), via HDX; National IPC Technical Working Group".

Added because the GeoJSON carries no dates (docs/data-sources.md section 7). Credit: "Integrated Food Security Phase Classification (IPC), via HDX; National IPC Technical Working Group".
- `hdx_ipc_nogeo_package.json`: https://data.humdata.org/api/3/action/package_show?id=kingdom-of-eswatini-acute-food-insecurity-country-data; CC0; untrimmed. **For the "no areas" test.** On 2026-11-23 no current country dataset lacked a GeoJSON; this is the old Eswatini duplicate (2017 to 2024, only CSVs), which shares the group `swz` with the current `eswatini-acute-food-insecurity-country-data` that has `ipc_swz.geojson`. A country with no IPC package at all (UKR, MMR) is the other "no areas" case and needs no file. Credit: "Integrated Food Security Phase Classification (IPC), via HDX; National IPC Technical Working Group".
